Week 01 · The file, and how it holds together — Lesson

DSGN 105 · Digital Imaging

Read this before the session. About 15 minutes.

This is the first week, so nothing is assumed. What it adds is the one idea the rest of the course is built on: an image file is not a picture. It is a record of how a picture was made, and in this course that record is part of what you hand in.

1 · Raster and vector

Digital images are stored two ways.

Raster images are a grid of pixels. Each pixel holds a colour, and the image is however many pixels wide by however many tall. Photographs are raster. Everything in this course is raster.

Vector images are stored as mathematical paths — a line described by its endpoints rather than by the pixels along it. Logos and type are usually vector. Vector is owned by DSGN 107, and you will meet it properly there.

The difference that matters right now is what happens when you make an image bigger.

Raster Vector
Has a fixed number of pixels. Enlarge it and the software has to invent the new ones Has no pixels until it is drawn. Enlarge it and it is redrawn at the new size
A photograph enlarged 4× looks soft or blocky A logo enlarged 40× looks identical
The pixel count is a hard limit on physical size There is no equivalent limit

That last row is the one to keep. A raster image carries a fixed amount of information, and no amount of enlarging adds more. You will meet the consequences of this properly in week 3.

2 · Layers

A layer is one stacked element of an image, editable without affecting the others. A composition built in layers can be rearranged, hidden, recoloured, and reordered indefinitely. The same composition flattened into one layer can be none of those things.

Layer groups collect related layers into one collapsible item. They are usually taught as tidiness. They are not tidiness — they are the difference between a stack somebody can read and a stack nobody can.

A nine-layer file with no groups is a list. A nine-layer file in three named groups is a description of how the image works.

A stack that cannot be read A stack that can
Layer 14 copy 3 Sky / gradient
Nine layers, flat list, no order Three groups: background, subject, type
Named after what was done to make it Named after what it is in the image

3 · Non-destructive editing

Non-destructive means any edit you can reverse without having altered the original pixels.

Take brightening an image. There are two ways to do it:

Destructive. Apply the brightness change directly to the pixels. The pixels are now different. If you decide tomorrow that it was too much, you cannot go back to what was there — you can only darken the already-brightened pixels, which is not the same thing and does not recover what was lost.

Non-destructive. Add an adjustment layer — a correction that sits as its own layer above the image, changing how it looks without changing what it is. Tomorrow you open the file, double-click the adjustment, and change your mind. The original pixels never moved.

Destructive Non-destructive
Changing your mind Start again Double-click the adjustment
What the file records The result The result and the decision
After a week You cannot tell what was done The decision is still sitting there, still editable

In this course, non-destructive is a requirement, not a preference. Three assessments look at how your files are built: this week's, week 5's composite, and the campaign image set, which is 25% of the campaign. A flattened file — one whose layers have been merged — cannot be assessed against any of them, because there is nothing left to look at.

There is a plainer reason too. A file another person can open and continue is a file you can hand to a client, a collaborator, or yourself in six weeks. A flattened export is a dead end for everybody including you.

4 · Why the reader matters

Here is the part that surprises people.

Your composition this week is not graded on how it looks. It is graded on whether another student can open it and carry on working.

That is not a proxy for how good it looks. It is the actual thing being tested, because a good-looking image proves almost nothing about who made it or how. An attractive flattened file could have been downloaded, handed over, or produced by following a tutorial keystroke by keystroke — and once the layers are gone, none of those are distinguishable from your own work.

The stack is the evidence. And legibility to somebody else is the one test of it you cannot mark for yourself.

Module 1 vocabulary

These belong to this module. Use them in the lab, the assignment, and the critique sessions later in the term.

Term Means
Raster Image data stored as a grid of pixels. What this course works in
Vector Image data stored as mathematical paths. Named here for contrast; owned by DSGN 107
Layer One stacked element of an image, editable without affecting the others
Adjustment layer A correction applied as its own layer, reversible without loss
Non-destructive Any edit that can be reversed without having altered the original pixels
Working file The layered file an image is built in and submitted as
Flattened An image whose layers have been merged, destroying the record of how it was built. Not acceptable as a working file

Words you will hear but do not own yet

  • Mask — a way of hiding part of a layer without deleting it. Mentioned in the demo. Owned and assessed in week 5.
  • Composition, visual hierarchy — you will hear these named this week so the words exist when you judge images in week 2. They are owned and assessed in week 4, where you perform them rather than recognise them.

Check yourself before the session

Not graded. Two of these matter more than the others.

  1. You need an image for a poster two metres wide. Does it matter whether the source is raster or vector? Why?
  2. What is the difference between hiding a layer and deleting it?
  3. You brighten an image, save, and reopen it a week later wanting it darker. What can you do — and what does the answer depend on? (If this is not obvious, re-read section 3.)
  4. Name two things a layer called Sky / gradient tells a reader that Layer 14 copy 3 does not.
  5. Why is "another student can continue your file" a better test of this week's outcome than "the image looks good"? (If this is not obvious, re-read section 4.)
  6. What does flattened mean, and why is a flattened file not acceptable as a working file here?

What happens in the session

You will watch the same correction applied two ways and then changed — which takes four minutes and settles the whole argument for non-destructive editing. Then you build a composition from supplied parts in the lab, and swap machines to read somebody else's.

Afterwards you finish it and submit it as the assignment, and choose the nonprofit your campaign will be built for.
