Week 01 Assignment — The collage

DSGN 105 · Digital Imaging

Formative · submitted and critiqued · 0% of your course grade.

It is required. Zero percent does not mean optional. Under the formative requirement, this must be submitted before week 2's module summative, and it is accepted late without penalty up until that point. After it, it is not accepted at all.

What to submit

One project folder, named exactly like this:

dsgn-105-collage-lastname

dsgn-105-collage-vanderpool. Lower case, hyphens, your surname. Not Collage Final, not dsgn105collage, not your first name.

Inside it, three things:

assets/ Every source image you used
exports/ Your export of the finished collage
The .psd The working file, at the top level of the folder

The document

Size 10 × 10 inches
Resolution 300 dpi — so 3000 × 3000 pixels
Colour mode RGB

Set this when you create the document. Resizing a raster file after the fact is not the same thing — you cannot add detail that was never captured.

What the .psd has to show

  • Layers, not a flattened image. One layer per element.
  • Groups, named for what things are. background, subject, type — not stuff or Layer 14 copy 3.
  • At least one adjustment layer, live, sitting above what it affects rather than inside it.

The file is the assignment. The picture matters, but what is being assessed is whether somebody else could open the file and understand how it was built.

Why assets/ is not optional

A working file points at its source images. It does not contain them. Hand someone a .psd without the assets and it opens with holes in it.

That is the whole reason the folder is structured this way — the project is the folder, not the file.

How to submit

  1. Put the project folder in Google Drive, in your course folder
  2. Paste the Drive link into Canvas — the link, not the files

Before week 2's session.

What does not count

  • A flattened file. There is nothing to assess. A merged composition cannot be distinguished from an image you downloaded, and the outcome is about how it was built.
  • A beautiful composition with an unreadable stack. Nine layers named Layer 14 copy 3 fail this assignment however good the picture is.
  • A loose .psd with no folder around it. The structure is part of the submission.
  • An empty assets/ folder. If the images are only on your desktop, nobody else can open your file.
  • The wrong document size. 10 × 10 at 300 dpi. Check it before you build, not after.

Use the glossary

The terms that matter this week: raster, layer, adjustment layer, non-destructive, working file, flattened, export, file format. All are in the Glossary under Module 1.

Rubric

LO 1 — Raster software

Use industry-standard software to create, edit, and manipulate raster-based digital images for print and screen.

This week evidences the construction half only. Print and screen destinations arrive in week 3 and are assessed in the campaign's output package.

Level
Exceeds The folder is named correctly, complete, and the stack is legible enough that somebody else could open it and keep working
Meets Folder structure correct, document at 10 × 10 at 300 dpi, layers grouped and named for what things are, adjustment layer live and above what it affects
Approaching The collage is made but the file is thin — ungrouped layers, missing assets, or the wrong document size
Not yet A flattened file, or no working file at all

The same four levels apply to every assignment in this course. Full descriptors: competency rubric.
