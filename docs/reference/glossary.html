DSGN 105 — Course Glossary

The controlled vocabulary for this course. Every artifact — student brief, rubrics, instructor guide, module plans, slides, LMS pages, assignment titles — uses these terms and only these terms.

How to use it: before any content ships, check every term in it against this list. If a word appears in the Never use column, replace it. If a needed term is missing, add it here first, then write the content.

One term, one meaning, everywhere. A student who learns a word in week 1 must find that same word in week 8 — and in an eight-week course there is no time to absorb a synonym.

How this document is organised

Part Holds Who it is for
1 · Course-wide Structure, assessment, and what students hand in alongside every submission Everyone, every week
2 · Module vocabulary The teaching vocabulary, grouped by the module that owns it The week that teaches it

A module owns a term. It is introduced there, assessed there, and used freely everywhere after. A week needing a word another module owns names the owning module rather than redefining it.

Where a term is introduced in one week and assessed in another, both are stated. Visual hierarchy is the standing example: named in passing in week 1, owned and assessed in week 4.

Part 1 · Course-wide

Term Means Never use
Course summative The awareness campaign. 70% of the course grade, running weeks 1–8. capstone, culminating assessment
Campaign The student's finished body of work — five to seven images for one organization. series
Phase One of the six numbered stages of the campaign. Phases run alongside the taught weeks; they are not weeks. stage, sprint, iteration
Checkpoint The end of a phase, where a deliverable is submitted. milestone, due date, gate
Component One of the seven graded parts of the campaign, lettered A–G. sub-project, graded item
Container A component that holds the campaign together but evidences no learning outcome — the campaign brief and the walkthrough. filler, overhead, scaffolding
Deliverable A specific thing a student submits or performs. hand-in
Module One of four blocks of weeks sharing a subject. chapter
Formative An assessment whose purpose is feedback. Submitted, responded to, and worth 0% of the course grade. ungraded, practice work, homework
Formative requirement The rule that formative work must be submitted before the summative or phase it feeds. Accepted late without penalty until that point. gate, eligibility rule
Module summative The assessment closing a module, judging whether its outcomes were reached. Four in this course, worth 30% between them. unit summative, big assignment
Practical A module summative where the student makes something. performance task, hands-on
Rehearsal A module summative that requires, at low stakes, the exact habit a later phase demands. Weeks 3 and 4. warm-up, dry run
Critique Observed evaluation of images the student did not make, covering clarity, ethical use, and appropriateness. Four sessions, weeks 4–7. crit, peer review
Critique record The written account of what a student said in a critique, made at the time. The only evidence for the evaluation outcome. write-up, meeting minutes
Disclosure statement The declaration submitted with every deliverable: which images are the student's own, where anything else came from, and how generative AI was used. AI disclosure, AI statement
Survey Material named and explained so the vocabulary exists, but not performed and not assessed. The week it returns is always stated. overview, FYI
Lesson outcome What a student can do by the end of a week that they could not do at the start. Numbered week.n. objective, learning target
Competency One of the six abilities the course assesses, one per course outcome, scored on the same four levels every week. proficiency
Asset An image or media item a slide requires, tagged FIND · MAKE · SHOW · DIAGRAM · NONE. resource
Course outcome One of the six outcomes in the course specification. Written LO n. CLO (in student-facing text)

Part 2 · Module vocabulary

Module 1 · Foundations and ethics — weeks 1–2

Term Means Never use
Raster Image data stored as a grid of pixels. What this course works in. bitmap, pixel image
Vector Image data stored as mathematical paths. Named here for contrast; owned by DSGN 107. line art, scalable image
Layer One stacked element of an image, editable without affecting the others. plane, canvas level
Mask A non-destructive means of hiding part of a layer without deleting it. Introduced week 1, owned and assessed in week 5. eraser, cutout
Adjustment layer A correction applied as its own layer, reversible without loss. correction layer
Non-destructive Any edit that can be reversed without having altered the original pixels. safe editing
Working file The layered file an image is built in and submitted as. native file, master file
Flattened An image whose layers have been merged, destroying the record of how it was built. Not acceptable as a working file. baked
Generative AI A tool that produces image content from a written input. gen AI, the AI
Input What the student gives a generative tool. Retained and submitted. query, command
Retention Keeping every generated output, kept and rejected, as submitted evidence. archiving
Provenance Where an image came from, and what permission its use requires. origin story
Misrepresentation Manipulation that causes a viewer to believe something untrue about the subject. Distinguished from manipulation that clarifies. doctoring, deepfake

Module 2 · Specification — week 3

Term Means Never use
Destination The specific place an image is going — a stated print size and stock, or a stated platform and placement. Never "print" or "digital" alone. endpoint
Specification statement The written record of pixel dimensions and resolution, file format, and colour system chosen for one destination, with the reason for each. spec sheet, tech specs
Pixel dimensions The width and height of an image in pixels. The only measure that exists in the file itself. canvas size
Resolution Pixels per unit of physical output. Meaningless without a stated physical size. sharpness (as a synonym)
ppi Pixels per inch — a property of an image prepared for a physical size. dpi (when the image is meant)
dpi Dots per inch — a property of a printing device, not of an image file. ppi (when the device is meant)
File format The container an image is written to, each with a different cost. encoding
Colour system The model describing how colour values are stored — RGB, CMYK, Lab. colour mode, colour profile
Gamut The range of colours a system can express. What is lost moving RGB to CMYK. palette
Export Writing a file for a destination from a working file. The working file is never the delivery. save as, render

Module 3 · Composition and construction — weeks 4–5

Term Means Never use
Composition The deliberate arrangement of elements within a frame. framing (alone)
Visual hierarchy The order in which elements are noticed. A property of how an image is read, not of how it was made. Named in week 1, owned in week 4. focal point (alone)
Reading order The sequence a viewer actually notices things in — first, second, third. eye path, scan pattern
Reading-order test Asking viewers who have not been told the intent what they noticed, in order. user test, poll
Leading Telling a viewer what to look at before asking what they saw. Invalidates the test. prompting the viewer
Compositional mechanism The specific choice producing the reading order — scale, contrast, placement, direction, or isolation. visual device
Isolation Separating an element from its surroundings so it is noticed first. negative space (alone)
Selection A defined region of an image, made in order to act on it. cutout, marquee (alone)
Composite One image built from more than one source. montage, collage, mashup
Join Where two composited sources meet. Judged at 100%, never at fit-to-screen. seam

Module 4 · The campaign delivered — weeks 6–8

Term Means Never use
Retouching Editing a photograph so it communicates more clearly than the original did. Not the same as cleaning it. touch-up, cleanup
Treatment The consistent visual handling applied across a set — tonal, colour, and textural. style, filter, aesthetic, vibe
Consistency The property of a treatment holding across a set. Cannot be judged within a single image. cohesion, uniformity
Unedited original The photograph as captured, submitted untouched alongside the retouched version. Required — it is the comparison retouching is graded against. raw (unless the file is genuinely raw)
Before-and-after pair An unedited original shown with its retouched result. side-by-side
Sequence The order images are arranged in so the set carries what no single image does. image order
Walkthrough The live account of the campaign, image by image. A container — it evidences no outcome. presentation, pitch, defence
